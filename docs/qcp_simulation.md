# QCP 可视化仿真

## 启动

在仓库根目录运行：

```bash
python -m pip install -r simulations/python/qcp/requirements.txt
python simulations/python/qcp/visualize_qcp.py
```

仅可视化需要 NumPy 和 Matplotlib，求解器及原性能测试仍可独立使用。交互窗口需要可用的桌面图形后端。图中使用英文标签，避免缺少中文字体影响显示。

无桌面环境时，执行方向扫描并导出图片及 CSV：

```bash
python simulations/python/qcp/visualize_qcp.py --headless --frames 72
```

默认输出到仓库的 `reports/simulations/python/qcp/`。可通过 `--output-dir` 指定其他目录，同名输出会覆盖。`--grid-size 241` 可加密参考网格，`--repeats 100` 可增加每帧的求解耗时采样数。

## 看什么

- 左图：线性约束形成的多边形、二次约束边界、绿色网格可行域、红色星形最优点，以及橙色网格参考点。紫色箭头指向目标函数增大的方向，红色虚线是经过求解结果的目标等值线。
- 右上：每次参数更新后的最优目标值与网格参考值，越大越好。固定约束旋转目标方向时，可以看出最优点如何沿圆弧或多边形边界移动。
- 右下：每组参数重复调用原 Python 求解器的耗时中位数和最大观测值，虚线为 1000 微秒预算。
- 状态栏：约束残差 `g(x)`、与网格参考的目标值差、求解耗时和网格搜索耗时。`VALID` 表示返回点通过多边形与二次约束容差检查；`CONSTRAINT VIOLATION` 表示返回可行标志但检查失败。

不可行时，方形标记仅显示原算法返回的尽力点，不绘制为已认证的最优点。网格没有找到可行点时，参考值缺失；这不能单独证明数学上不可行。

## 交互操作

- `Angle`：目标方向（度）。
- `Radius`：圆半径；在其他模式下调整二次约束水平。
- `Clip x`：半平面 `x <= Clip x`。
- `Vertices`：初始凸多边形顶点数（3 到 16），裁剪沿用原求解器的容量限制。
- `Center x`：二次曲线中心的横坐标。
- `Circle / Near-singular / Infeasible`：普通圆、近奇异矩阵、严格不可行约束三种模式。
- `Play sweep / Pause`：自动旋转目标方向。每一步均重新调用求解器。
- `Save PNG/CSV`：保存当前图像及完整参数历史，文件为 `interactive_snapshot.png` 和 `interactive_history.csv`。

图中的动态过程是参数扫描，不是算法迭代收敛。当前算法是解析枚举法，没有迭代轨迹。右侧曲线保留最近 180 帧，CSV 保留本次会话的全部历史；修改参数后曲线上的相邻点可能对应不同的约束问题。

## 精度与计时口径

网格搜索采用 NumPy 批量计算，有限网格上的最大值是原问题最优目标值的近似下界，不能作为精确最优值认证。求解器允许的数值容差也会影响比较。默认网格覆盖 `[-2.25, 2.25]²`，包含本仿真的整个多边形。

求解延迟采样前预热 5 次，计时只包含 `QcpSolver2D.solve()` 调用及计时开销，不包含输入构造、网格参考计算或绘图。网格耗时包含其约束检查和目标筛选，排除坐标网格构造；与预热后的单次解析求解口径不同，不应据此声称严格的算法加速倍数。绘图、调度及系统负载仍可能影响下一次测量。此工具用于直观探索，正式吞吐和尾延迟比较请使用 [性能测试脚本](benchmarks/qcp.md)。
